# 브레이크아웃팀2

쿨라매기의 "강하게 오른 뒤 횡보 수렴 → 돌파"를 **볼린저 밴드 숫자**로 찾는 팀입니다.

- **대시보드:** https://305rhfueo-ui.github.io/breakout-team2/
- **전략 설명:** [strategy.html](strategy.html)
- **촉매 등급 기준:** [docs/catalysts-v3.md](docs/catalysts-v3.md)

## 구성
| 담당 | 하는 일 | 방식 |
|---|---|---|
| 돌파 찾기 | 6가지 조건(150일선 위 · 전날 폭 ≤0.25 · 전날 상단 아래 → 당일 상단 위 · 상단↑ 하단↓ · 거래량 50일 평균 위) | 코드 |
| ① RS 돌파 | + RS 1·3·6개월 중 하나라도 상위 2% | 코드 |
| ② 촉매 돌파 (검증 중) | + 촉매 등급 S/A | AI(원문 확인) |
| 실장 | 코드 순위 검토 → 최종 추천 0~3 | AI |
| 모의투자 | 두 에이전트 신호를 전부 같은 규칙으로 (실장과 별도) | 코드 |
| 추적·뉴스 | 돌파 뒤 60거래일 · Nasdaq·CNBC·야후·SEC 기사 | 코드 |

## 실행
```
bash deploy/run-job.sh daily          # 1팀 morning.sh 맨 끝에서 매일
node scripts/scan.js --label=YYYY-MM-DD   # 지난 장 다시 판정 (사이트 히스토리 라벨)
node tests/run-all.js
```

## 전제
- 같은 맥미니의 `~/AI/breakout-team`(1팀) 모듈을 경로로 빌려 씁니다. 그래서 이 저장소 혼자서는 돌지 않습니다. 다른 위치면 `BT_ROOT`로 지정합니다.
- 1팀 `.env`(텔레그램)를 그대로 읽습니다. 이 저장소에는 키가 없습니다.

## 규칙
- 공개 저장소입니다. 금액·수량은 쓰지 않습니다. 수익률은 계좌 대비 %로만 씁니다.
- 판단 보조이며 매매 권유가 아닙니다. 최종 결정은 본인입니다.
